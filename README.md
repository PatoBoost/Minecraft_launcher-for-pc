# Minecraft Launcher for PC

A simple and lightweight custom Minecraft launcher for PC.
## Supported Operating Systems
* 🪟 **Windows**
* 🍎 **macOS**
* 🐧 **Linux**
## Features
* Fast game launch (You can optimize specs for example RAM etc. 9GB
* Simple and clean user interface
* Built for PC (Windows,macOS and Linux) better than normal Minecraft launcher

## How to Download
1. Go to the **Releases** section on the right side of this page.
2. Click on the `MINECRAFT` tag release.
3. Download the executable file for Windows , Mac and linux and run it.
